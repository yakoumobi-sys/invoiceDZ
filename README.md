# invoicedz

Factures, devis, proformas, bons de commande et bons de livraison en ligne — 100% gratuit, pensé pour l'Algérie (TVA, droit de timbre, montant en lettres, CRM clients, catalogue produits, mode invité).

- Site : https://invoicedz.vercel.app
- Démarrer en local : `npm install && npm run dev`
- Tests : `npm test`
- Détails de la mise à jour : voir `MISE-A-JOUR.md`
